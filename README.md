# Round One

Street Fighter II Champion Edition oyuncularını nick üzerinden aramak için hazırlanmış, mobil uyumlu bir sıralama sorgulama uygulaması. Oyuncunun dünya sırası, ELO puanı, Fightcade rütbesi, toplam maç sayısı, oyun süresi ve ülkesi gösterilir.

## Teknolojiler

- TanStack Start ve React
- TypeScript
- Tailwind CSS ve özel CSS
- Netlify

## Yerelde çalıştırma

```bash
pnpm install
pnpm dev
```

Uygulama statik sıralama verisini `public/data/sf2ce-rankings.json` dosyasından okur.
